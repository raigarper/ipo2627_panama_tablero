Cómo se juega

El objetivo es conseguir que cada fila del tablero contenga fichas de un único tipo.

  • Arrastra una ficha y suéltala sobre otra celda para intercambiar su posición.
  • Sin ratón: pulsa una celda para seleccionarla y pulsa otra celda para intercambiarlas. Usa Tab para moverte entre celdas y Enter o Espacio para seleccionar.
  • Cambiar el tamaño N, el tamaño de las fichas o su aspecto comienza una partida nueva.
